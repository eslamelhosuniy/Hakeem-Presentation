1.1 Problem Statement

Finding the Right Fit Takes Too Long

From the Employer's Perspective

  • Avg. 23 hours screening resumes per hire
  • Thousands of applications, inconsistent criteria
  • Prolonged time-to-hire and elevated costs

From the Job Seeker's Perspective

  • Minimal feedback, opaque application status
  • No guidance on suitable roles
  • Fragmented tools create data silos

The Core Problem

Most platforms treat these as separate problems — job boards on one side, recruitment tools on the other.

Scout Talent addresses these challenges through a single, cohesive AI-powered platform.

3.2 & 3.3 Frontend & Backend

Core Technologies Deep Dive

Presentation Layer

  • FrameworkReact 19 + Vite 7 + TypeScript
  • RoutingAuthRoute + ProtectedRoute (role-based)
  • HTTPAxios-based services per domain
  • WebSocketSocket.IO Client (persistent)
  • Pages40+ pages across 5 directories

Application Layer

  • FrameworkNestJS 11 — 18 domain modules
  • AuthJWT + Google OAuth2 + RBAC
  • QueueBullMQ async task processing
  • SecurityHelmet + Throttler (10 req/60s)
  • AI ModulesRecommendAiModule + RecommendAiCompanyModule
HAKEEM07 / Tech Stack

3.4 AI Engine

Hakeem AI Microservice

  • Core Technology Python 3.10+ processing Semantic Vector Embeddings via LLM Provider Factory.
  • CV-to-Job Matching Recommends the most relevant job roles to candidates based on their uploaded CV automatically.
  • Job-to-Candidate Scoring Ranks and scores a full pool of applicants for HR teams, eliminating manual review.
  • Multi-Factor Scoring Formula Final Score = Semantic Similarity + Skill Overlap + Experience Match
Vector Storage
Qdrant VectorDB
High-dimensional embeddings for fast semantic similarity search
Two collections:
recommend-jobs  |  recommend-candidates
